\# Ecom Store



A full-stack e-commerce web application built with PHP and MySQL. The project includes customer authentication, product browsing, shopping cart, checkout, order management, inventory management, and an admin dashboard.



\## 🚀 Features



\### Customer Features



\- User registration and login

\- Secure password hashing

\- Product listing

\- Product details

\- Product images

\- Shopping cart

\- Increase/decrease cart quantity

\- Remove products from cart

\- Clear cart

\- Stock validation

\- Checkout

\- Order placement

\- Order history

\- Order details

\- Order status tracking

\- Responsive user interface



\### Admin Features



\- Secure admin login

\- Admin dashboard

\- Product management

\- Add products

\- Edit products

\- Delete products

\- Product image upload

\- Inventory/stock management

\- View customer orders

\- Update order status

\- Sales statistics

\- User statistics

\- Order statistics



\## 🛠️ Technologies Used



\- PHP

\- MySQL

\- PDO

\- HTML5

\- CSS3

\- XAMPP

\- phpMyAdmin

\- Git

\- GitHub
